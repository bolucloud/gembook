# Planning

Our team will build an app called ##Gembooks. We plan on performing both individual and pair programming on some advanced features.

## Features
- View list of contacts
- Add a contact
- Update or Edit a contact
- Delete a contact
- Search a contact
- Birthday's
- Favorites list
- Export contacts

## Definition of Done
For this project to be done, the below requirements must be met:
- Application running without crashes
- Graceful error handling of user inputs
- All features work without errors
- All tests suites pass
